# Assetra

An AI-powered portfolio management platform for stocks, ETFs and Crypto Assets.

Assetra combines modern full-stack engineering, AI agents, and machine learning to help investors track portfolios, analyze risk, optimize personalized asset allocation, and receive personalized investment insights.


## Packages

| Path | Description |
|------|-------------|
| [`frontend/`](frontend/) | Next.js application, portfolio dashboard, authentication, portfolio management, and AI Advisor interface |
| [`mle/`](mle/) | Machine learning pipeline for portfolio analytics, market data ingestion, feature engineering, and risk modeling |

See [`mle/README.md`](mle/README.md) for the machine learning architecture and portfolio risk engine.
